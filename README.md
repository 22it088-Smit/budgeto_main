# Budgeto

A comprehensive money management app designed to help users take control of their finances.

## Features

- Budget tracking and management
- Expense categorization (Need, Expenses, Savings)
- Transaction history
- Planning tools
- Dark/Light theme support
- Local data storage

## Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio / VS Code with Flutter extension

### Installation

1. Clone the repository
```bash
git clone https://github.com/yourusername/budgeto.git
```

2. Navigate to the project directory
```bash
cd budgeto
```

3. Install dependencies
```bash
flutter pub get
```

4. Run the app
```bash
flutter run
```

## Usage

1. Register with any email and password
2. Set up your budget split (Need, Expenses, Savings)
3. Add income and track expenses
4. Use planning tools to manage future expenses
5. View your financial summary on the home screen
